# نکات امنیتی مهم در پشتیبان SISE

- در بررسی Supabase، جدول private.api_rate_limits با RLS خاموش گزارش شده است. این مورد به‌عنوان هشدار امنیتی مهم ثبت شد و در این بسته هیچ تغییری روی دیتابیس زنده اعمال نشده است.
- schema با نام private معمولاً از Data API عمومی expose نمی‌شود؛ با این حال باید تنظیمات Exposed Schemas و مجوزهای نقش‌ها بررسی شود.
- پیش از فعال‌کردن RLS روی private.api_rate_limits، باید مشخص شود کدام تابع سروری به آن دسترسی دارد و سیاست مناسب یا دسترسی محدود از طریق تابع امن تنظیم شود؛ فعال‌کردن بدون بررسی ممکن است rate limit را از کار بیندازد.
- کلیدهای OTPy، OpenRouter، Supabase service role/secret، رمز دیتابیس و OAuth secret داخل بسته نیستند.
- سورس دو تابع تست OTP با کلید ثابت redacted شده است؛ برای عملیات واقعی deploy نکنید.
- این نسخه شامل schema و کد است، نه اطلاعات سفارش‌ها، کاربران، پیام‌ها یا فایل‌های Storage.
